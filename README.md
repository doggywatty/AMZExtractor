# AMZExtractor

AMZExtractor is a tool for extracting files from Android Market ZIP (`.amz`) archives.

## Overview

This project provides a way to unpack `.amz` files and access their contents.

## Usage

```
AMZExtractor <input.amz> [options]

Options:
    -o, --out <dir>   Output directory (default: <input>_extracted)
    -l, --list        List entries only, write nothing
    -h, --help        Show this help
```

## Features

- Extracts files from `.amz` archives.
- Provides access to the contents of Android Market ZIP files.
